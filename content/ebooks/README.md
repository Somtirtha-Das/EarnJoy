# EarnJoy E-books

Upload future E-book PDF files and other approved reading materials into this folder.

## Upload guidance
- Keep E-book files inside this `content/ebooks/` folder.
- Use clear, descriptive filenames, for example `business-fundamentals.pdf`.
- When uploading a new E-book, share its title, topic/category, short description, cover image (if available), and preferred display order so the EarnJoy E-books page can be updated to list it.

Files added to this folder will not automatically appear on the website until the page catalogue is updated.
